# Simulaci-n-del-sistema-de-la-Biblioteca-Escolar
Nuestro programa abarca el sistema que maneja la biblioteca del tecnológico de Valladolid, en la cual se tomó en cuenta la cantidad de estudiantes que prestaron libros, y el tiempo que tardaba en atenderlos, como solo es un bibliotecario, si eran varios alumnos, tenían que esperar su turno.
